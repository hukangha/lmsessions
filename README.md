# lmsessions

List, copy, move, search, view, remove or resume Claude Code, Codex, OpenCode and Google Antigravity sessions in a vim-ish style

Run with no arguments for the interactive menu:

`/`  to search

`v` to open vim viewer

`s` to sort

ls/cp/mv to list, copy and move sessions. -h for subcommands' help.

cp/mv supports remote dir with ssh.

Requires Python 3.10+
